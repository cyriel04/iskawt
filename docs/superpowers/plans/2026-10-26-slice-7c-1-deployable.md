# Slice 7c-1 — Deployable Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Iskawt deployable to Vercel + Neon as a clearly-marked portfolio demo: demo flag, photo-required publishing, photo-aware seed, production-gated build script, Sentry smoke route, and demo marking in the UI.

**Architecture:** One new column (`Space.isDemo`) flows through the existing public select into `SpaceCard`. `publishedWhere` gains a photo condition so every public read inherits it. The seed reads committed JPEGs from `public/demo/<slug>/` through small pure helpers. A bash build script, selected by `vercel.json`, gates migrations and seeding on `VERCEL_ENV`. The UI marks demo spaces in `PhotoFrame`, a final gallery tile, and a layout banner.

**Tech Stack:** Next.js 16.4 App Router, Prisma 7 + `@prisma/adapter-pg`, Jest 30 + RTL, MUI 9 + SCSS modules, `@sentry/nextjs` 11.4, bash.

**Spec:** `docs/superpowers/specs/2026-10-23-slice-7c-ship-design.md` (section "7c-1 — Deployable")

## Global Constraints

- No new dependencies. Node built-ins (`fs`, `path`, `crypto`, `child_process`, `os`) only.
- TypeScript strict: no `any`, no `@ts-ignore`, no `!`.
- Tests before implementation; every new test must be seen failing first.
- Never hand-edit `prisma/migrations/**`; create the migration with `pnpm db:migrate --name space_is_demo`. Local Postgres is Docker (`docker compose up -d`; if the socket is down, `open -a Docker` and wait for `docker info`).
- Public queries use explicit `select`. `isDemo` is public; nothing else new is selected.
- Styling: SCSS modules with tokens from `app/_styles/_tokens.scss`. No `sx`, no `style={{}}`, no raw hex/px colours or spacing. Touch targets ≥44px only where interactive (none here).
- Copy, verbatim:
  - Photo badge: `Demo photo · not a real space`
  - Final gallery tile: `Demo listing, for internal use only. Photos, rates and host are not real.`
  - Site banner: `This is a demo. Every listing is sample data.`
  - Demo alt prefix: `Demo photo: `; placeholder alt: `Demo placeholder: <space type label>`
- Ops message added: `"[ops] sentry smoke test"`. Nothing from the request is ever logged or sent.
- The build script never echoes environment values.
- Commit at each task's last step, message ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push.
- Done = `pnpm typecheck`, `pnpm test`, `pnpm lint` all clean.

## Rulings made while planning

- **Fixture line in `app/_components/testing.tsx`.** Adding `isDemo` to `SpaceCard` breaks the shared fixture. Task 1 (backend-dev) adds `isDemo: true` to `demoCard` there — one line, test fixture only — so the tree typechecks at every commit. Approved by the main session.
- **Smoke route has two modes**, instead of "schedule then throw" in one request: if `after()` callbacks don't run when a handler throws, one combined request couldn't tell which path failed. Default mode schedules `opsError` in `after()` and returns 202; `?mode=throw` throws. Same key check for both.
- **404 body.** The route returns `new Response(null, { status: 404 })`. Route handlers can't render the app's not-found page; an empty 404 reveals nothing either.
- **Seed helpers live in `prisma/demoPhotos.ts`** so they can be unit-tested; `seed.ts` runs `main()` on import and can't be.

```ts
// Pure helpers for the demo seed's photos, split out so they can be tested.
// seed.ts runs on import and can't be.

import fs from "node:fs";
import path from "node:path";

export type DemoPhotoRow = { url: string; alt: string; isCover: boolean; sortOrder: number };

const PHOTO_FILE = /^(\d+)\.jpe?g$/i;
const numberOf = (name: string): number => Number(PHOTO_FILE.exec(name)?.[1] ?? Number.NaN);

export function demoPhotoFiles(names: readonly string[]): string[] {
	return names.filter((name) => PHOTO_FILE.test(name)).sort((a, b) => numberOf(a) - numberOf(b));
}

export function readDemoPhotoFiles(slug: string): string[] {
	const dir = path.join(process.cwd(), "public", "demo", slug);
	if (!fs.existsSync(dir)) return [];
	return demoPhotoFiles(fs.readdirSync(dir));
}

export function buildDemoPhotos(input: {
	slug: string;
	title: string;
	typeLabel: string;
	placeholder: string;
	alts: readonly string[];
	files: readonly string[];
}): DemoPhotoRow[] {
	if (input.files.length === 0) {
		return [{ url: input.placeholder, alt: `Demo placeholder: ${input.typeLabel}`, isCover: true, sortOrder: 0 }];
	}
	const plainTitle = input.title.replace(/^\[DEMO\]\s*/, "");
	return input.files.map((file, index) => {
		const n = numberOf(file);
		return {
			url: `/demo/${input.slug}/${file}`,
			alt: input.alts[n - 1] ?? `Demo photo: ${plainTitle}, photo ${n}`,
			isCover: index === 0,
			sortOrder: index,
		};
	});
}

export function assertNoRealSpaces(realSlugs: readonly string[]): void {
	if (realSlugs.length > 0) {
		throw new Error(`Refusing to seed: these slugs belong to non-demo spaces: ${realSlugs.join(", ")}`);
	}
}
```

// Stub prisma, pnpm and next on PATH. Each appends its argv to a log; FAIL_ON
// makes the stub whose argv matches exit 1.
function run(env: Record<string, string>) {
	const dir = fs.mkdtempSync(path.join(os.tmpdir(), "vercel-build-"));
	const log = path.join(dir, "log");
	for (const bin of ["prisma", "pnpm", "next"]) {
		const stub = path.join(dir, bin);
		fs.writeFileSync(

fi

echo "▸ next build"
next build

// Post-deploy check that Sentry receives events from production (docs/deploy.md).
// Locked behind OPS_TEST_KEY; without it this is indistinguishable from no route.
// Default: an ops message sent from after(), which proves after() flushes.
// ?mode=throw: an unhandled error, which proves route errors are captured.
// Nothing from the request is logged or sent.

import { createHash, timingSafeEqual } from "node:crypto";
import { after } from "next/server";
import { opsError } from "@/app/_lib/server/opsLog";

export const dynamic = "force-dynamic";

// Hash both sides so the compare is constant-time whatever the lengths.
const digest = (value: string) => createHash("sha256").update(value).digest();

function authorised(request: Request): boolean {
	const expected = process.env.OPS_TEST_KEY;
	const given = request.headers.get("x-ops-key");
	if (!expected || given === null) return false;
	return timingSafeEqual(digest(given), digest(expected));
}

export async function GET(request: Request): Promise<Response> {
	if (!authorised(request)) return new Response(null, { status: 404 });

	if (new URL(request.url).searchParams.get("mode") === "throw") {
		throw new Error("Sentry smoke test");
	}

	after(() => opsError("[ops] sentry smoke test"));
	return Response.json({ scheduled: true }, { status: 202 });
}
